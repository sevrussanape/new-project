# AI Stock Price Prediction Dashboard

Full‑stack app with React, Flask, and Random Forest.

## Quick Start

1. Double‑click `run.bat` (Windows) or run:
   - Backend: `cd backend && pip install -r requirements.txt && python app.py`
   - Frontend: `cd frontend && npm install && npm start`
2. Open `http://localhost:3000`

## Features

- Search any stock ticker
- Display company info, current price, day high/low, volume
- 1‑year historical chart
- 7‑day price prediction
- Model evaluation (MAE, RMSE, R²)

## Tech Stack

- React, Tailwind, Chart.js
- Flask, yfinance, scikit‑learn
